# Cookbooks

Short step-by-step recipes for adding tests. Each cookbook links to a reference
spec in the repo — copy patterns, don't reinvent.

| Recipe | When to use |
|---|---|
| [Add a Todo UI test](./add-todo-ui-test.md) | New browser test on TodoMVC demo |
| [Add a Users API endpoint](./add-users-api-endpoint.md) | New REST method with stub + contract + live coverage |
| [Add a Conduit flow](./add-conduit-flow.md) | New RealWorld API, UI, cross-layer, or IDOR test |

**Before starting:** read [architecture.md](../architecture.md) and the relevant
domain map ([conduit-map.md](../conduit-map.md) for Conduit).
